# Comprezzor by Rinaldisign

Image compressor di browser (JPEG, PNG, WebP) — tanpa upload ke server.

## Fitur
- Kompres satu gambar: perbandingan asli vs hasil, kontrol format, kualitas & target ukuran
- Batch folder: pilih folder, semua foto dikompres ke target ukuran (default 2.5 MB), format output bisa dipilih, hasil diunduh sebagai ZIP
- Multi-bahasa: Indonesia, English, 日本語
- PWA (bisa diinstal)

## Cara pakai
Buka `index.html` di browser atau deploy sebagai static site. Tanpa dependency/build step.
